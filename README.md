# quran-app-assets

Files the [free Qur'an recitation app](https://github.com/NaderAbsy) downloads on demand. Nothing
here is modified.

## `qcf2-1421/`: Madinah mushaf page fonts, 1421H print

- `QCF2001.ttf` … `QCF2604.ttf`: one font per page of the Madinah mushaf (1421H print,
  Uthman Taha), as produced by the **King Fahd Glorious Qur'an Printing Complex**, Madinah
  (QCF V2). All rights belong to the Complex. The Complex's font page states its fonts are free to
  copy, distribute and use, personally and commercially.
- Unmodified. Every file is byte-identical in two independent copies: the
  [nuqayah/qpc-fonts](https://github.com/nuqayah/qpc-fonts) mirror and Quran.com's font CDN.
- `SHA256SUMS` lists each file's checksum. The app checks it after downloading.

If you represent the King Fahd Complex and want these removed, please open an issue.
